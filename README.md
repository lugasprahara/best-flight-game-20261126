**Kestrel Circuit** — an original chase-view flight game in vanilla JavaScript and Canvas, no build step and no network. You fly the little Kestrel K-1 over a painted island archipelago through four sorties: thread the dawn rings, chase fuel drums before the tank runs dry, punch through the storm line, then slow down and land her on the harbour runway. The flight model rewards throttle and turn discipline — the wing stalls, a banked turn costs height, fuel burns with the throttle, and storms, peaks and birds cost hull. A lit instrument panel (attitude indicator, airspeed, altimeter, heading tape, throttle quadrant, warning lamps) and a full HUD with altitude, speed and heading fly with you. Steer with the arrow keys, A/D, the mouse or a drag; W/S or the wheel works the throttle; P pauses, M mutes the synthesised engine.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser — or open game/index.html through any static file server
```
